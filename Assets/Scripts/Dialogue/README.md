# 钴蓝对话与回应原型

依据 `Assets/ObsidianDocs/NPC Dialog System/` 的 GDD/TDD，以及 `NPC 钴蓝 CoBlues.md`、`NPC_CoBlues 钴蓝/` 的人物设定与对话示例。初次谈话以卖画与钱展开；熟悉后的卖画话题保留她怕丢脸、回避问题的语气。新增台词是可改写的原型剧本。

## 入口与操作

正常运行 SampleScene，停车后按 F 下车。起点车辆附近原有示例 NPC 现在装配钴蓝对话组件。没有修改场景或覆盖 NPC 通用预制体；其他 NpcActor 保留原行为。

- 靠近并停留片刻，钴蓝会主动开口。玩家头顶出现三点聊天气泡时，按住 Tab 展开回应，滚轮、↑↓ 或 W/S 选择，松开 Tab 发送。下一组需要重新按住；不会连续发送。
- 选项采用屏幕右侧无框文字，金色标示当前选择；字号由 24 改为 20，渲染时加入细字距；NPC 和玩家各自的台词用浅色圆角气泡跟随各自头顶显示，气泡与三点图标的尖角都在底部正中央朝下，双方文字按每秒 22 字逐字出现并居中对齐；气泡从默认 140×44 的参考尺寸开始，逐字按已显示文字扩宽，达到最大宽度后换行增高，保持尖角与人物中心对齐。完整显示后保留阅读时间再淡出。游戏 UI 不放按键说明、设置、历史或存读档按钮。
- 回复窗口改为 36 秒，整段时间保留全部选项；取消 6／12／18 秒的分阶段失效。第一项固定为默认的“...”。选中它释放 Tab 仅收起选项，不提交、不生成台词、不重置时间，可以再次按住 Tab 展开同一组。36 秒仍未发言才按沉默进入情境收尾。主动话题菜单不计时。
- 计时条始终显示，不必按住 Tab；移除了阶段刻度。暂停、失焦或控制台占用期间计时冻结，恢复后须重新按住才能提交；失焦回调或键盘／手柄断开也会立即取消待发送选择。离开再接话或读档不能刷新当前回应时间。
- 本次交互修改依据用户 2026-10-04 的新要求；`responseSeconds` 定义整组回应时长。旧 `expiresAfterSeconds` 字段保留兼容读取，运行时不再使用。
- E 拾取附近的蓝色旅行颜料、递给钴蓝或踩住帐篷布。压布持续五秒完成，再次 E 或离开取消。
- Esc 进入告别收尾，再次 Esc 可立即结束。手柄对应按住 LB、方向键选项、松开 LB 发送，B 退出、X 环境动作。
- 按住 Tab 选台词时暂停移动，Shift 独立用于疾跑，选项滚轮不改变镜头缩放。保存与读取 API 保留供开发工具调用。
## 内容与运行责任

靠近 10 米并停留约 0.65 秒触发一次主动招呼；结束后不会因为一直站在旁边就反复开口。重新离开、回来并经过冷却，才重新招呼。交谈有效距离为 20 米；超过 20 米或听不见满 3 秒才挂起，返回 20 米内可接续，保留已用回应时间。不再在 3.6 米处提前告别；递物仍需 2.5 米。NPC 对话不使用 F 和问号／感叹号；其他物体交互保持原样。

入口优先检查初见、已有承诺／逾期、携带颜料、真实赠送回响、帮过帐篷，再检查时间和最近实际听到的话题。短暂离开后延续已交付的话题，不随机换成另一个话题。新分支包含画中的细节、本子、鱼、清晨烧水、夜间收画。节点 silenceNext 指定沉默后继；无选项的 endAfterSeconds 节点自动收尾，原有承诺与记忆交付边界保留。

`Resources/Dialogue/CoBlues.json` 按画画、卖画、颜料、捕鱼、笔记和营地生活组织短段落，使用稳定英文 ID；内容不执行任意代码。每条玩家回应应直接接住上一句，后继节点先回答这句，再展开后续。条件不满足的 fallback 也必须回答原问题，不能无故跳回菜单。

节点 `topic` 标注主题，`leaveNext` 指定当前情境的告别，`returnEntry` 记录重新靠近时可延续的话题。只有实际交付给玩家的台词才更新最近话题。会话内 `heardNodes` 避免重新提问已经回答的非终止节点；没有新问题时自然收尾。实际递出颜料、完成压布会替换旧回应组，使旧命令失效；颜料已经补足后不会再次声称缺货。

`Core/` 是无 Unity 引用的状态与命令核心。选择提交、玩家话语交付、NPC 听见、NPC 接受、物品转移是分开的步骤。上下文由场景适配器在每次交付时重新提供，包含交谈距离、阻挡与递物距离。

`CoBluesDialogue` 负责一个前台会话的场景接入、输入、中文 IMGUI 字幕与无框选项。`DialogueSaveStore` 在同步命令边界保存 JSON，并通过临时文件和替换保留上一版 `.bak`。

“帮你留意”只留下弱证据；“明天给你带一管蓝色颜料”在钴蓝接受后建立承诺，期限为成立时下一世界日结束。真实递物才履行。钴蓝在绝对世界时间 60 小时自主补充颜料，解除未履行承诺。逾期记录为事实，不直接扣好感。

同次相处的同类弱证据聚合。相处时间段为六个世界小时，反复走出范围不能刷新贡献。颜料回响要求真实赠送记忆且至少过去一个世界日，后续引用也有一个世界日冷却；熟悉话题要求至少两个相处时间段的已观察经历。

## 玩家行为与钴蓝的观察

同组回应允许意思相近的接话、眼前细节和轻微岔题，不要求每句话都表明不同倾向。普通接话不设置玩家自述意图。常用 NPC 节点的 `textVariants` 在后续会话轮换；只有已呈现的台词才推进轮换，暂停、走远和读档接续保留原句。

台词以一次一件事为单位，正文校验上限 38 字、选项上限 24 字；承诺仍明确说出明天和一管颜料。追问展开细节，不把整段说明塞进一句话。

观察来自已听见的话语、明确沉默、实际帮忙及可见的停留。16 类观察入口涵盖话少、健谈、好奇、画画兴趣、生活细节、关心吃饭休息、帮忙、反复回来、安静陪伴、匆匆离开，以及玩家明确说出的安静、聊天、无聊、休息、路过和思考。判断用问句，选项允许纠正，剧情回应不把猜测当作人格定论。

- 两段回应窗都在有效计时结束前未发言，才会询问是否想安静；选中“...”松键本身不计作沉默证据。暂停和失焦不推进计时。
- 六次已交付发言、四次问句、三次画画追问、三次生活细节追问，分别形成不同观察；关心吃饭休息需要两次不同会话。
- 送过颜料并完成压布，才会提起两件帮助。口头说帮忙不算完成。
- 一世界小时内多次回来，以及听见招呼后很快离开，分别形成“想聊天？”和“在忙？”的询问。
- 已认识玩家、非对话中、相距三米内、互相可见，且原地停留 45 秒，才会主动询问是否想歇脚。只计算水平移动，地面重力不算走动。
- 每次评论后间隔至少 90 秒，已评论过的证据不会重复使用。24 世界小时以前的行为不再支持当前判断。玩家明确要安静、休息或思考时，不反复用陪伴问题打扰。
- 玩家说出的意图保留到后续见面，并可改口。“无聊”可以继续为看画挑一处问题，也可以只是聊天或歇着；没有凭空承诺新任务。

作者工具的 `Preview and Inspect` 显示观察计数、已评论计数、玩家自述和待触发入口。观察保存在对话存档里；恢复旧存档时缺失的观察列表按空列表处理。

## 保存边界

存档位置为 `Application.persistentDataPath/coblues-dialogue-v1.json`。包含对话世界时钟、颜料库存/领取状态、需求、承诺、记忆、已知事实、近期已呈现台词、会话安全点、结果去重 ID。加载不会重放物品转移，未完成的发言与持续动作安全取消。

这是对话子系统存档，不保存车辆位置、地形改动或整个游戏。文件或内容版本不兼容时拒绝加载并保留原文件；没有实现任意版本自动迁移。新版本须显式提供迁移。

## 验证与作者工具

### 在 Obsidian 中编辑剧情

打开 `Assets/ObsidianDocs/NPC_CoBlues 钴蓝/CoBlues.playable.md`，修改节点或回应下方以 `> ` 开头的台词。多行台词每行都加 `> `，空段落写成单独的 `>`。节点和选项的元数据保留 ID、条件、后继与结果；不要删除这些围栏块。

保存后回到 Unity 会自动校验并导入；也可使用 `Voyage > Dialogue > Import Markdown Story`。无效分支会报错并保留之前的有效内容。进入新的 Play Mode 会话使用导入后的剧情。`Validate Markdown Round Trip` 检查分支、条件、单行／多行台词和回应的往返保真。

对话时按住 **Tab**，用 **↑／↓、W／S 或滚轮**选择回应，松开 Tab 发送。Shift 仍用于疾跑。

- `Voyage > Dialogue > Validate CoBlues Content`：检查重复 ID、后继引用、回应数量、条件与承诺接受节点。
- `Voyage > Dialogue > Preview and Inspect`：在编辑器内预览节点、回应、赠送及时间变化，或只读检查当前游戏中的会话 ID、槽位版本、事件交付、记忆来源与承诺状态。
- 构建前自动执行同一内容校验，错误配置会阻止构建。
- `Voyage > Dialogue > Run Core Tests In Place`：保持当前场景，执行只创建对话状态的 NUnit 测试方法；结果写入 `Logs/DialogueValidation/core-tests.txt`。
- `Voyage > Dialogue > Run Scene Input Probe`：进入 Play Mode 且场景加载后执行真实输入系统测试。测试会停稳车辆、下车、移动玩家，完成对话和道具交付，仅用于测试运行；退出 Play Mode 还原场景。测试不覆盖玩家存档，截图与结果写入 `Logs/DialogueValidation/`。
- Unity Test Runner 的 `Voyage.Dialogue.Tests` 程序集可完整执行同一套测试。常规 Test Runner 可能要求处理未保存场景，请先自行保存。
