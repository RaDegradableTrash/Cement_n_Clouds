# 可编辑的草

Unity 菜单：**Tools → Voyage → Terrain Density Painter**（原 **Grass Painter** 入口也保留）。请在非运行状态编辑。

窗口顶部的 **Scene 窗口显示云层** 默认关闭，只影响编辑器 Scene 视图，Game 视图和游戏中的云不受影响。

点击 **显示全部地形 / Show entire terrain**，Scene 窗口会显示并框选整张地图的红绿权重。全图使用已有合并网格和临时拾取碰撞体，可直接在任意位置绘画，无需逐块点击加载。全图用 4096² 贴图缩略显示已有权重，尚未绘制的地形显示默认 78% 权重。落笔只记录笔画并更新预览，不加载地形源模型、不栅格化区块、不创建草地资产。点击应用后才按原网格生成涉及的原始 256² 区块权重，每个缺失区块只生成一次。全图展示精度不影响保存精度。

1. 点击 **显示全部地形**。可用 **框选全图** 恢复总览。
2. 选择 **草地密度** 或 **道路 · 浅棕泥土**，勾选 **启用绘画笔刷**。
3. 鼠标左键拖动刷草；按住 **Shift** 拖动擦除。**Ctrl+Z / Ctrl+Y** 撤销或重做。全图默认启用 **俯视编辑（防止缩放穿地）**：滚轮围绕鼠标位置缩放，中键平移。点击 **返回地表俯视编辑** 可恢复局部俯视；取消俯视编辑后可用 Alt 自由旋转场景视角。
4. Radius 支持 1–1024 米半径；12m、256m、1024m 按钮可快速切换。Strength 控制强度，Hardness 控制软边，Target density 控制目标密度。
5. 全部画完后点击 **应用全部绘画 / Apply all painting**，一次性处理并保存。松开鼠标只保存轻量笔画草稿。关闭窗口、重新编译或进入 Play 不会自动应用；草稿保存在 `Library/VoyageTerrainPaintSession.json`，重新打开全图即可继续。删除 Library 会丢失未应用草稿，已应用资产不受影响。

默认开启 **显示红绿权重**：红色表示高密度（1），绿色表示低密度或无草（0），中间颜色连续混合。可直接点击“红色 · 茂密”或“绿色 · 稀疏”设置目标。全图模式关闭权重显示后显示地形底色；若要查看局部实际草地及精细权重，可加载附近区块并点击 **隐藏全图**，局部灰色表示不可种草的表面。

道路工具绘制浅棕色泥土，应用后由实际地形和远景的地表着色器共同显示，并接受光照、阴影和雾。道路覆盖图保存在 `Assets/Resources/TerrainSystem/TerrainRoadMap.asset`（4096²）。每次新刷道路会清除该笔刷范围内的草；之后切回草地工具即可重新种草，道路不会持续阻止草生长。Shift 擦路只还原地面颜色，不自动恢复草。笔画按先后顺序应用。

编辑更新独立草地密度和道路覆盖贴图，不改变原始模型、顶点或三角形。**撤销上一次编辑（保留历史）**：有待应用笔画时撤销最后一次完整拖动；没有待应用笔画时撤销最后一个已应用批次。**恢复上一次撤销** 可以恢复笔画或已应用批次，**编辑历史** 可查看批次状态。撤销不删除历史记录。已应用批次使用按钮管理，不依赖 Unity 临时的 Ctrl+Z 栈；Ctrl+Z 仍可撤销待应用笔画。

已应用批次的修改前后快照保存在 `Library/VoyageTerrainPaintHistory`，重开工具或编辑器仍然保留；删除 Library 会清除这份历史。撤销后应用新批次，会保留旧分支记录，但不再提供旧分支的直接恢复，以免覆盖新编辑。局部区块加载按钮仍会立即读取模型，只在确实需要精细局部预览时使用。

首次打开一个区块，会按可种草的网格表面创建 78% 密度的初始分布。重新打开已有区块不会覆盖绘画。已准备出生点附近 3×3 共 9 块；地图其余区域需按需加载、创建和绘制，未绘制区域在游戏中按区块分帧生成草，保存的笔刷数据优先且不会被覆盖。

绘画保存在 `Assets/GrassFlowPaint/Resources/GrassFlow/Tiles`。选择相应 Grass 资源可调整草高、每行候选草数量和显示距离。每行数量的平方就是该区块的候选数：默认和上限为 256² = 65,536 个草簇位置。默认 Golden Meadow 为细密金色草甸：近景 56 根细叶、中景 18 根、远景 7 根，16 米和 38 米切换 LOD，最远 90 米，并按距离减密。草根逐根贴合地形；世界坐标噪声控制轻微疏密变化，连续风场形成麦浪。提高数量或显示距离会增加 GPU 开销。

`Assets/TerrainSystem/Source/TerrainChunkSettings.asset` 的 **Use Painted Grass** 已开启，用于停用旧的运行时草生成。旧代码与原有分布资源仍保留，便于回退。昼夜颜色和轮胎附近的压草效果沿用项目参数。

验证覆盖笔刷增删、跨块接缝、Undo、网格覆盖范围、实际 URP 绘制、昼夜颜色和清空密度后的 GPU 实例移除。受控渲染对比可通过 Unity batchmode 执行 `GrassFlowBenchmark.Run`（不要加 `-quit`，工具会在采样结束后退出）。该对比包含同步读回，不能当作完整游戏帧率。


样式名称约定：**“芦荟” = Aloe**，专指此前宽叶、放射状草簇版本（9 / 5 / 3 片叶）。此版本已保留，但不再默认启用。选择 Grass 资源，将 Style 改为 Aloe 即可恢复；Golden Meadow 是当前细密金色草甸。这个称呼用于后续交流与版本识别。

Golden Meadow Palette 调整新草甸根、叶和叶尖色；Aloe palette 下原有颜色用于芦荟。Wind Strength 控制风力。样式切换不覆盖已画密度。

车辆轮胎由现有 GrassInteractionSystem 注册接触并生成压草场，新草甸逐根响应，包含静止压力和随时间恢复；其他移动物体可添加 GrassInteractionEmitter。没有逐根草的物理 Collider。



性能修复：进入 Play Mode 自动清除笔刷预览，避免重复渲染。未绘制区块仅在接近时生成，多个区块共享每帧约 1.5 ms 的栅格化预算。草与地面共享 VoyageMeadowLighting 光照、阴影和底色，远景覆盖感由底色衔接。


灰麦色修订：降低饱和度，增加短草与长草的高度层次。草甸颜色以线性 Vector 数据传入，避免 Color 属性的色彩空间转换与地面常量不一致。草根使用地面法线、共用环境光和阴影，不额外叠加根部染色。远景描边使用倒数深度的不连续检测，避免连续坡面产生横带；地形深度与颜色通道共用 LOD/范围裁剪。芦荟仍保留原配色与模型。

远景轮廓修订：44 / 15 / 5 片叶的小幅加密，保持原笔刷遮罩。近远景共用雾后暗色描边；低于 1.5 米的深度跳变不描边，以抑制草叶噪点。Persistent distant terrain 使用原地形 LOD3，每 8×8 个 tile 合批，不带草、碰撞或阴影投射，最远可见 12 公里。修改地形后使用 Voyage > Terrain > Rebuild distant horizon 重建远景资源。
描边深度单独绘制地形和物体，排除 VoyageGrass（第 8 层），避免密草形成暗带。自定义相机的 Culling Mask 需要包含 VoyageGrass 才能看见草。
